# Changelog

Maintain `CHANGELOG.md` using Keep a Changelog format.

- Add notable features, fixes, and breaking changes under `## [Unreleased]`.
- Skip refactors, typos, CI changes, and other internal-only work.
- Keep each entry to one terse line and include the bead reference when one
  exists.
- Use `Added`, `Changed`, `Fixed`, and `Removed` sections.
- At release time, move unreleased entries to `## [x.y.z] - YYYY-MM-DD`.
